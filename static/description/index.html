How It Works

Streamlined 4-Stage Inspection Workflow

STEP 01

Register Pipeline & ISO

Record line numbers, operating/design pressures, temperatures, pipe schedules, corrosion allowances, and isometric drawings.

STEP 02

Map Structural Supports

Attach structural supports (Support Code / Level / Pipe Ref) and classify them across 19 standard CUPS configurations.

STEP 03

Execute 9-Point Grading

Evaluate each support on 9 critical criteria with mandatory validation, condition badges, engineering comments, and field photos.

STEP 04

Generate A4 PDF Dossier

Export a complete External Visual Inspection Report with isometric previews, condition legends, checklists, and indexed photo appendices.

📋 9-Point Examination Checklist

Every structural support is evaluated across nine standardized engineering activities with dedicated comment, recommendation, and photo fields:

01 General Visual Condition of Support MANDATORY
02 Corrosion Under Pipe Support (CUPS) MANDATORY
03 External Mechanical Damage MANDATORY
04 External Corrosion MANDATORY
05 Misalignment OPTIONAL
06 Leakage Detection OPTIONAL
07 Pipe Shoes Off / Displaced OPTIONAL
08 Loose Brackets & Fasteners OPTIONAL
09 Insulation Damage OPTIONAL

🎯 Standard Severity Grading

Code C — Satisfactory:
Support is in excellent structural condition.
Code B — Less Significant Fault:
Surface light rust or minor corrosion detected.
Code A1 — Significant Fault:
Moderate surface rust or moderate corrosion detected.
Code A2 — Imminent Danger:
Heavy rust or severe structural corrosion requiring action.
